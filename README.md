# iLoveChem — Universal Computational Chemistry File Converter

**iLoveChem** is a free, high-performance, 100% in-memory computational chemistry and CADD file converter designed for quantum chemistry, molecular docking, and crystallography.

### Key Capabilities:
- **Quantum Formats:** ORCA, Gaussian (`.com`/`.gjf`), Q-Chem, VASP, NWChem, Molpro, GAMESS
- **Structural Biology & Docking:** PDB, PDBQT, Mol2, SDF, XYZ, CIF, SMILES, InChI
- **2D/3D ChemDraw Reaction Schemes:** CDXML SuperAtom expansion, multi-molecule ZIP batch extraction
- **Strict In-Memory Privacy:** Pharma-grade volatile RAM execution — zero user data written to disk.
